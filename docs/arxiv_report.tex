\begin{abstract}
We introduce the Hui-Muslims dataset, a specialized, high-quality Retrieval-Augmented Generation (RAG) corpus containing 232 native Chinese articles. 
\end{abstract}
\section{Introduction}
This dataset bridges the gap in low-resource cultural alignment for Large Language Models (LLMs).
\section{Methodology}
Articles were extracted from Salaamalykum.com, cleansed of HTML, and converted to Markdown with robust YAML metadata.
