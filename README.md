# Hui Muslims RAG Corpus

[![Dataset on Hugging Face](https://img.shields.io/badge/Dataset-Hugging%20Face-yellow)](https://huggingface.co/datasets/qurancn/Hui-Muslims)
[![License](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A curated dataset of **232 articles** detailing the culture, history, mosques, and culinary traditions of the Hui Muslim community in China. Designed specifically for **RAG (Retrieval-Augmented Generation)** pipelines and LLM pretraining.

## Project Iqra Standards Compliant
This repository adheres to the dual-track publishing protocol:
1. **Human View**: `232` formatted Markdown files in `content/` with full YAML metadata.
2. **Machine View**: Parquet dataset hosted on Hugging Face.
3. **AI Discovery**: SEO heartbeat workflows, Schema.org JSON-LD, and `/llms-full.txt` index.

## Structure
- `content/`: Markdown articles.
- `docs/`: Jupyter notebooks for data exploration.
- `llms-full.txt`: Consolidated text format for fast crawler ingestion.
